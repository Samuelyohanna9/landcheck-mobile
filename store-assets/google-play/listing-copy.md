# Google Play Listing Draft

## App name

`LC Green`

## Short description

Field tree monitoring, planting records, maintenance tasks, and offline sync.

## Full description

LC Green is the field app for LandCheck Green.

It is designed for planting teams, supervisors, custodians, and project staff who need to record tree activity in the field and keep project evidence organized.

Key capabilities:

- Secure staff login by organization and project scope
- Map-based tree capture for new planting and existing tree inventory
- GPS-backed field records
- Camera and photo-library evidence attachment
- Maintenance task updates and review workflow
- Offline capture with automatic sync when connectivity returns
- Project monitoring aligned with LandCheck Work administration and reporting

LC Green is intended for operational field use in reforestation, agroforestry, and related land-restoration programs.

Important:

- A valid organization account is required
- Access is controlled by your organization administrator
- Some features require location and camera permissions to record field evidence correctly
